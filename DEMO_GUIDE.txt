PART 3: KEY TECHNICAL QUESTIONS & ANSWERS (VIVA PREPARATION)
================================================================================

Q1: Why did you use FaceNet instead of traditional OpenCV Haar Cascades?
A1: Haar cascades only detect presence of faces and struggle with lighting and
    angles. FaceNet maps facial features into a 512-dimensional continuous Euclidean
    space where distance directly corresponds to facial similarity. It is invariant
    to pose, lighting, and expressions.

Q2: How does face matching work in the backend?
A2: When a camera frame arrives, MTCNN detects and crops the face. FaceNet extracts
    a 512-d normalized vector. The backend performs vectorized Cosine Dot Product
    against the gallery vectors in MongoDB. If similarity >= 0.65 threshold, attendance
    is recorded.

Q3: How is duplicate attendance prevented?
A3: The MongoDB `attendance` collection enforces a compound unique index on
    `{student_id: 1, session_id: 1}`. Any secondary check-in attempt is caught
    both at the service layer and database layer.

Q4: What cloud services are used?
A4: - Compute: AWS EC2 (Elastic Compute Cloud) running Ubuntu/Windows.
    - Database: MongoDB Atlas cloud replica set with TLS/SSL encryption.
    - API: FastAPI asynchronous web framework with Uvicorn ASGI server.
    - Security: IAM Role with least-privilege policies.

PART 4: EMERGENCY TROUBLESHOOTING (QUICK COMMANDS)
================================================================================

1. If the EC2 backend crashes or freezes:
   Run in EC2 PowerShell:
   Get-Process python -ErrorAction SilentlyContinue | Stop-Process -Force
   cd C:\Users\Administrator\Desktop\smart-attendance
   .\.venv\Scripts\Activate.ps1
   $env:PYTHONPATH = ".;backend;ml"
   python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000

2. If the frontend says "Failed to fetch" or connection refused:
   - Ensure local frontend is running: `python -m http.server 3000`
   - Test backend health in PowerShell:
     Invoke-RestMethod -Uri "http://3.7.55.180:8000/api/attendance/sessions/active"

3. If the browser shows old cached UI:
   - Press Ctrl + Shift + R (Hard Refresh) in Chrome.
